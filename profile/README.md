### Why Amazon Quick?

- **AI-native** — Built-in generative AI for data analysis, document research, and natural language interactions across your entire organization.
- **Comprehensive platform** — Dashboards, workflows, automation, collaborative spaces, and apps in one unified experience.
- **25+ connectors** — Integrate with Salesforce, Jira, ServiceNow, Slack, Microsoft Teams, SharePoint, Confluence, and more.
- **No AWS account needed** — Get started for free at [quick.aws.com](https://quick.aws.com) with email, Google, Apple, or GitHub login.
- **MCP and A2A support** — Model Context Protocol and Agent-to-Agent interoperability for extensible AI workflows.
- **Desktop and Web** — Native desktop application plus full browser-based access with Quick Desktop Skills and Quick Automate.
