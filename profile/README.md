### Platforms

| | |
|---|---|
| **[Quick Web](https://quick.aws.com)** | Browser-based access — Flows, Automate, Spaces, Research, Apps, and embedded analytics |
| **[Quick Desktop](https://aws.amazon.com/quicksuite/)** | Native desktop application — local file integration, meeting prep, and context-aware assistance |
| **[Quick Mobile](https://aws.amazon.com/quicksuite/)** | On-the-go access to dashboards, alerts, and AI-powered insights |
